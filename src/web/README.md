# ZŠMP web (Next.js)

Next.js port of the old static site (formerly `html/`, still available in git history). It renders the same pages with the same look.

## Run

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start   # production
npm run lint
npm run format         # Prettier; format:check only checks
```

## Layout

- `app/` one folder per page, same URLs as before without `.html` (e.g. `/organizace/skola`). Pages were converted from the old `html/**/*.html`.
- `app/layout.tsx` shared shell: header, cookie bar, seasonal background, footer.
- `components/` client pieces that replaced the jQuery in `index.js` (sticky header, cookie bar, carousel, gallery).
- `lib/navigation.ts` main menu items.
- `app/styles.css` the original `styles.css`, plus a few lines for the native video player. Bootstrap 5 comes from npm.
- `public/` static files copied as-is: `data/images`, `informatika/` (Myšák, Scratch projects, PDFs).
- `next.config.ts` redirects old `*.html` and `/galerie/<id>/galerie.html` links to the new URLs.

## Galleries

`/galerie/<id>` shows the photos in `public/galerie/<id>/`. An optional `meta.json` sets the heading:

```json
{ "title": "Mikuláš 5.12.2023" }
```

Thumbnails are generated by `next/image`, so the Python gallery generators are not needed. Gallery pages read the folders on every request. This will move to the backend once uploads exist. `public/galerie/ukazka` is a sample.

## Not in this repo

These folders exist only on the live server: `dokument/`, `data/videos/`, `galerie/`. For local development copy them into `public/`; in Docker they are mounted from the host (see the root README).
